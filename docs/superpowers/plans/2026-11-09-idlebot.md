# IdleBot Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Operar quatro sessões locais de caça e comercialização com um painel ao vivo.

**Architecture:** Um processo Node mantém perfis Playwright separados, transforma eventos da sessão em registros SQLite e serve o painel via HTTP local e SSE. A política de operação é independente da automação de navegador.

**Tech Stack:** Node 24, SQLite, Playwright Core, Edge e JavaScript.

**Spec:** `docs/superpowers/specs/2026-11-09-idlebot-design.md`

## Global Constraints

- Até quatro perfis. Cada perfil usa a sessão de uma conta própria.
- O painel fica disponível apenas neste computador.
- Publicações e saques aguardam confirmação do jogo.
- Um resultado incerto bloqueia a repetição automática da operação.
